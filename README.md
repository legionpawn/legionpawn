# Legion Pawn Management

Static web app backed by Supabase (`index.html`), ready to host on **GitHub Pages**.

## Hosting on GitHub Pages

1. Create a new repository on [GitHub](https://github.com/new) (e.g. `legion-pawn`).
2. Upload `index.html` and `.nojekyll` (plus any backup `.json` files if desired) to the root of the `main` branch.
3. In your repository, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**, select **`main`** and **`/ (root)`**, then click **Save**.
5. Wait ~1 minute and open `https://<your-github-username>.github.io/<repo-name>/`.
